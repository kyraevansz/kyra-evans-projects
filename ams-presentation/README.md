# Obstructions to Geometric Vertex Decomposability of Toric Ideals of Graphs

Slides from my talk at the American Mathematical Society 2026 Fall Eastern Sectional Meeting held at George Washington University. 
This is joint work with Sergio Da Silva, Munso Bwalya, and Russell Humphrey.

## How to view the slides

1. Click [Obstructions to GVD Kyra Evans.pdf](Obstructions%20to%20GVD%20Kyra%20Evans.pdf).
2. GitHub will say "Binary file not shown." That's normal for PDFs.
3. Click **View raw** (or the download icon) near the top right of the file box. The slides will open in a new tab.
